# Privacy Policy for CurioCut Automation

Last updated: November 2026

## 1. Information We Collect
CurioCut accesses public Instagram comments on reels published by @curiocutt to provide automated resource link delivery via Direct Message when requested by the commenter. We do not store, sell, or share personal user data.

## 2. Use of Data
Data accessed via the Meta Graph API is used solely to:
- Identify trigger keywords (e.g. 'JARVIS', 'LOCAL') in public comments.
- Deliver direct links to referenced open-source software and documentation.
- Maintain public comment responses.

## 3. Data Deletion
Users may request data deletion or opt-out at any time by sending a message to @curiocutt on Instagram or opening an issue on GitHub.

## 4. Contact
For any privacy questions or inquiries: contact@curiocut.internal
